Updating the Android App on Your Phone

Here's the full workflow every time you want to push changes to your phone:

Step 1 — Build the web app

Open a terminal inside hebrew-kids-app/ and run:

npm run build

This compiles your React code into the dist/ folder.

Step 2 — Sync with Capacitor

npx cap sync android

This copies the dist/ files into the Android project and updates any Capacitor plugins.

(Your npm run android:sync script likely does steps 1+2 together — check package.json to confirm.)

Step 3 — Open Android Studio

npx cap open android

Or use your npm run android:open script.

Step 4 — Connect your phone

  • Enable Developer Options on your phone (tap Build Number 7 times in Settings → About Phone)
  • Enable USB Debugging in Developer Options
  • Connect phone via USB and accept the "Allow USB Debugging" prompt on the phone

Step 5 — Run on your phone

In Android Studio:

  1. Wait for Gradle to finish syncing (progress bar at the bottom)
  2. Select your phone from the device dropdown (top toolbar)
  3. Click the green Run ▶ button

Android Studio will build the APK, install it on your phone, and launch the app automatically.

Quick Reference (every update)

1. npm run build

2. npx cap sync android

3. npx cap open android

4. (in Android Studio) select phone → Run ▶

Optional: Install APK manually (without Android Studio each time)

After step 2, you can build a release APK directly:

  • In Android Studio: Build → Build Bundle(s) / APK(s) → Build APK(s)
  • Find the APK at android/app/build/outputs/apk/debug/app-debug.apk
  • Transfer it to your phone (via cable, WhatsApp, Google Drive, etc.) and install it

This is useful when you want to share the app or don't want to keep Android Studio open.
